# AI-Powered Fraud Detection & Risk Analytics Dashboard

An AI-powered fraud detection project that uses Machine Learning and Power BI to identify fraudulent transactions and analyze transaction risk.

## Project Features

- Fraud transaction detection using Machine Learning
- Random Forest classification model
- Fraud probability prediction
- Risk level classification
- Power BI interactive dashboard
- Actual vs Predicted Fraud analysis
- Confusion Matrix
- Model Performance analysis
- Fraud Probability by Hour
- Risk Score analysis
- Interactive Risk Level and Hour filters

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
- MySQL
- Power BI
- Git & GitHub

## Machine Learning Model

The project uses a Random Forest classification model for fraud detection.

### Model Performance

- Accuracy: 99.98%
- Precision: 91.16%
- Recall: 94.32%
- F1-Score: 92.71%
